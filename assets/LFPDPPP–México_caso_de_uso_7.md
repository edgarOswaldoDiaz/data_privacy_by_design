# Caso de uso 7. BellezaPersonalizada

## 1. Contexto

BellezaPersonalizada es una empresa que comercializa productos cosméticos mediante una plataforma digital.

Utiliza sistemas de inteligencia artificial para recomendar productos a partir de fotografías, preferencias, historial de compras y cuestionarios sobre características de la piel.

## 2. Problema empresarial

La empresa utiliza fotografías de sus clientes para entrenar modelos de inteligencia artificial sin informar claramente sobre esta finalidad.

Además, conserva las imágenes originales aun después de generar las recomendaciones solicitadas.

Algunos clientes descubren que sus fotografías fueron utilizadas para mejorar herramientas comerciales sin que conocieran ese tratamiento.

## 3. Solución propuesta

- Diferenciar el uso de fotografías para recomendaciones del uso para entrenamiento de modelos.
- Informar de manera clara sobre ambas finalidades.
- Obtener el consentimiento que corresponda según la naturaleza de los datos.
- Evitar conservar imágenes cuando ya no sean necesarias.
- Implementar controles para impedir accesos no autorizados.
- Establecer procedimientos para atender derechos ARCO.

## 4. Aplicación de la LFPDPPP

**Artículo 5:** establece los principios de finalidad, consentimiento, información y proporcionalidad.

**Artículo 6:** exige respetar la confianza y expectativa razonable de privacidad del titular.

**Artículo 7:** regula el consentimiento.

**Artículo 8:** establece requisitos para el tratamiento de datos sensibles, cuando las imágenes o información recopilada tengan esa naturaleza.

**Artículo 13:** obliga a garantizar el cumplimiento de los principios.

El uso de información para entrenar modelos debe analizarse como una finalidad diferenciada del servicio solicitado.

## 5. Valor agregado

La empresa mejora la transparencia de sus herramientas de inteligencia artificial y reduce riesgos asociados al uso secundario de información personal.

## 6. Preguntas para un sistema RAG

1. ¿Puede una empresa utilizar fotografías para entrenar inteligencia artificial?
2. ¿Cuándo una fotografía constituye un dato personal sensible?
3. ¿Qué exige el principio de finalidad?
4. ¿Debe informarse sobre el uso de datos para entrenamiento de modelos?
5. ¿Qué derechos tiene una persona respecto de sus fotografías?

## 7. Resultados esperados

BellezaPersonalizada incorpora avisos claros, establece mecanismos de consentimiento y limita la conservación de imágenes.

## 8. Conclusión

El uso de inteligencia artificial no elimina las obligaciones de protección de datos personales. Las empresas deben informar las finalidades del tratamiento y respetar las decisiones de los titulares.
