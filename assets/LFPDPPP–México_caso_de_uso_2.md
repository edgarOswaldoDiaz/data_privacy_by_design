# Caso de uso 2. FinanCrédito Digital

## 1. Contexto

FinanCrédito Digital, S.A. de C.V., es una empresa privada que ofrece préstamos personales mediante una aplicación móvil.

Para evaluar las solicitudes recopila datos de identificación, ingresos, cuentas bancarias, historial crediticio e información laboral.

## 2. Problema empresarial

La empresa utiliza una casilla de aceptación general para autorizar tanto el tratamiento de datos necesarios para otorgar créditos como el uso de información financiera para elaborar perfiles comerciales.

Los solicitantes no pueden distinguir qué datos son indispensables para el préstamo y cuáles se utilizan con fines publicitarios.

Además, la empresa comparte información con agencias comerciales sin explicar adecuadamente las finalidades.

## 3. Solución propuesta

- Separar las finalidades necesarias de las finalidades secundarias.
- Obtener consentimiento expreso para datos financieros o patrimoniales cuando corresponda.
- Informar claramente sobre las transferencias de información.
- Permitir que los usuarios rechacen finalidades secundarias cuando proceda.
- Registrar las autorizaciones otorgadas.
- Revisar los contratos con terceros que reciben información.

## 4. Aplicación de la LFPDPPP

**Artículo 5:** establece los principios de finalidad, consentimiento, información y proporcionalidad.

**Artículo 6:** prohíbe obtener o tratar datos mediante medios engañosos o fraudulentos.

**Artículo 7:** exige consentimiento expreso para datos financieros o patrimoniales, salvo excepciones legales.

**Artículo 9:** establece situaciones en las que el consentimiento no resulta obligatorio.

**Artículo 13:** establece la responsabilidad del encargado de garantizar el cumplimiento de los principios.

La empresa debe distinguir los tratamientos necesarios para cumplir sus obligaciones de aquellos que requieren autorización adicional.

## 5. Valor agregado

Una gestión transparente del consentimiento fortalece la confianza de los usuarios y reduce el riesgo de reclamaciones relacionadas con el uso indebido de información financiera.

## 6. Preguntas para un sistema RAG

1. ¿Qué consentimiento requieren los datos financieros?
2. ¿Cuándo puede una empresa tratar datos sin consentimiento?
3. ¿Puede una financiera utilizar información crediticia para publicidad?
4. ¿Qué obligaciones existen cuando se comparten datos con terceros?
5. ¿Cómo puede revocarse el consentimiento?

## 7. Resultados esperados

FinanCrédito Digital implementa mecanismos diferenciados de consentimiento y permite que los clientes conozcan las finalidades para las cuales se utiliza su información.

## 8. Conclusión

El tratamiento de información financiera exige especial atención al consentimiento y a la transparencia. Una empresa debe evitar utilizar autorizaciones generales para justificar finalidades que no fueron explicadas adecuadamente.
